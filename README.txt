# MarketLens AI iPhone PWA

This version can be installed on an iPhone without a computer once hosted on an HTTPS website.

On iPhone:
1. Open the site in Safari.
2. Tap Share.
3. Choose “Add to Home Screen”.
4. Open MarketLens from the new icon.

This is a web/PWA version, not an App Store-signed native iOS binary. The interface is designed to feel like an iPhone app and can work offline for the cached prototype.

The prototype data is illustrative. Live market/news/economic APIs and an AI backend must be connected for production.
